# Chrono

Минималистичное Android-приложение с несколькими сохраняемыми таймерами.

## Сборка

Откройте проект в Android Studio с JDK 17 и Android SDK Platform 36 или выполните:

```sh
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions собирает тот же APK при push, pull request и ручном запуске workflow.

## Разрешения для будильников

Android может запросить специальный доступ к точным будильникам. Если он не выдан, таймер использует системное неточное срабатывание. На Android 14 и новее также разрешите полноэкранные уведомления приложения, чтобы экран будильника появлялся поверх блокировки. Для звука используется системный поток будильника.
